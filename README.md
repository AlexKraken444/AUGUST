# AUGUST

Бесконечный август на Next.js App Router и React.

1 августа 2026 года считается первым днем. 9 ноября 2026 года получается 101 августа. Счетчик никогда не сбрасывается в новом году.

Дата и время берутся с устройства посетителя. Номер дня рассчитывается по местной календарной дате, таймер считает до следующей местной полуночи, включая переходы на летнее время. Миллисекунды обновляются с частотой кадров экрана. В скрытой вкладке обновления приостанавливаются и сразу восстанавливаются при возвращении.

## Запуск

Требуется Node.js 20.9 или новее.

```sh
npm install
npm run dev
```

## Оформление

Адаптивный типографический плакат, бумажная текстура, анимированное солнце, светлая и темная темы, анимация смены дня. Учитывается системная настройка уменьшения движения. Декоративные элементы нарисованы CSS и SVG. Manrope загружается с Google Fonts, при отсутствии сети используется Arial. Основные цифры используют системный Georgia.
